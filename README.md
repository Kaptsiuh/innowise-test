# How to run the app

### Clone the repository:

- git clone https://github.com/Kaptsiuh/innowise-test.git

### Navigate to project directory:

- cd innowise-test

### Install dependencies:

- npm install

or

- pnpm install

### Development mode:

- npm run dev

or

- pnpm dev

### Production build:

- npm run build

or

- pnpm build
